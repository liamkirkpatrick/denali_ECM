# denali_ECM
Repository to explore Denali ECM data from '23 and '25 campaigns


NOTE:
- DC ECM data from the '23 campaign (denoted 'Basal_Liam') uses a different DC electrode system ("ballpoint pen style"). These electrodes proved more sensitive to noise and also small bits of loose snow. They should NOT be directly compared to DC ECM data from the '25 campaign, as this used the traditional "prong" style DC electrode.
